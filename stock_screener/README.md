# 個別株スクリーニング

東証プライムの主要銘柄（`tickers.py` に約80銘柄を収録）を対象に、PER・PBR・配当利回り・時価総額・ROE・出来高急増倍率・セクターの条件で絞り込める、Flask製の簡易スクリーニングアプリです。株価・指標データは [yfinance](https://pypi.org/project/yfinance/) 経由で Yahoo! Finance から取得します。

「出来高急増倍率」は直近の出来高が平均出来高（yfinanceの `averageVolume`）の何倍かを表す簡易指標です。機関投資家の売買動向や決算の上方修正といった情報はyfinanceでは信頼性高く取得できないため、現時点では未対応です。

このディレクトリは `youroku-app` リポジトリのルートアプリ（通知表所見文生成アプリ）とは独立した別アプリです。

## セットアップ

```bash
cd stock_screener
pip install -r requirements.txt
python app.py
```

デフォルトでは `http://localhost:5001` で起動します（`PORT` 環境変数で変更可能）。

## 使い方

1. トップページでPER上限・PBR上限・配当利回り下限・時価総額下限・ROE下限・セクター・並び替え順を入力（すべて任意）。
2. 「スクリーニング実行」を押すと、対象銘柄のデータをリアルタイムに取得し、条件に一致する銘柄を一覧表示します。
3. 取得した指標は30分間キャッシュされるため、同じ銘柄への再取得は高速化されます。

## 注意事項

- 実行環境からインターネット（Yahoo! Finance）へアクセスできる必要があります。プロキシ等で外部通信がブロックされている環境では、データ取得に失敗します。
- 対象銘柄は `tickers.py` のリストに限定されています。追加したい銘柄があれば、同ファイルに `{"code": "証券コード", "name": "銘柄名", "sector": "セクター名"}` を追加してください。
- 投資助言を目的としたものではありません。表示される指標はYahoo! Finance由来の参考値であり、実際の投資判断は自己責任で行ってください。

## テスト

ネットワークに依存しないフィルタ・ソートロジック（`logic.py`）は `tests/test_logic.py` でユニットテストできます。

```bash
cd stock_screener
pip install pytest
pytest
```
